Three ways back in.

Whatever state you are in, one short command.

Pack

Git state, your goal, and a session excerpt in one folder. This is the work, not a composer id.

$ hermes handoff

Find

See what Hermes can see on this machine. Search. You do not need every agent installed.

$ hermes list -q auth

Open

CLI agents (Claude, Codex, OpenCode…) start with the pack. Cursor gets the prompt on your clipboard — new chat, paste or @PROMPT.md.

$ hermes handoff claude cursor

Why is this not Catchup?

Do I paste PROMPT.md?
For Claude, Codex, OpenCode, Pi, Copilot, Cline: no, if that CLI is installed. Hermes starts it and points it at .hermes/seed.md. For Cursor and other editors: yes — they cannot import a native session. The pack is the continue path. Catchup does the same thing under another name: they seed a CLI, or they make you paste.
Does it merge two agents into one history?
No. One agent at a time. A handoff, not a blender.
Does anything leave my machine?
No. No npm skill, no MCP, no upload. One Go binary.
Do I need npm?
No. One Go binary. The install command puts it on your PATH.

Install

One binary. No npm. No plugin.

$ curl -fsSL https://raw.githubusercontent.com/Vinyl-Davyl/hermes/main/scripts/install.sh | sh

New terminal, then hermes doctor. If it is not found: export PATH="$HOME/.local/bin:$PATH"
